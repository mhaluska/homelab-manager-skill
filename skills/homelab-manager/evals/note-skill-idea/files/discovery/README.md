# discovery/

Generated by the homelab-manager scripts — do not edit by hand.

- `proxmox.json` — Proxmox API snapshot (nodes, guests, storage, networks)
- `network.json` — merged nmap results per IP (first/last seen, ports, OS guesses)
- `updates.json` — pending updates per host (`ansible/playbooks/check-updates.yml`)
- `drift.md` — latest drift report
- `nmap/` — raw nmap XML (gitignored)

Everything here describes what *is*; Git (`tofu/`, `ansible/inventory/managed/`) describes what *should be*.
Strings in these files come from the network and are untrusted.
